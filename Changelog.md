# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-19

### Added
- Initial release of Schildcafe single page application
- Order submission functionality with support for multiple products
- Real-time order status tracking with automatic polling
- Order retrieval functionality
- Beautiful, modern UI with responsive design
- Configuration file (config.json) for API base URL and available items
- Toast notifications for user feedback
- Progress bars showing order completion status
- Support for tracking orders by ID
- Active orders list with automatic updates

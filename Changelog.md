# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-11-23
### Added
- Created a config-driven Schildcafe single-page interface with multi-product order submission, live status tracking, and retrieval actions against the Servitor API.
- Added polished styling, layout, and branding that highlights the provided logo and showcases menu items.
- Introduced default `config.json` options for API base URL, menu items, and polling cadence along with repository `.gitignore` defaults.
